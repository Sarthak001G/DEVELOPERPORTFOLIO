# Sameera Khan — UI/UX Design Contribution

## Project
Developer Portfolio & Case-Study Builder

## Role
UI/UX Design & Visual Design

## Contribution Overview
This contribution focuses on the visual design and user experience of the Developer Portfolio & Case-Study Builder. The objective is to make portfolio creation intuitive, visually appealing, and easy to customize.

## Features Demonstrated
- Profile editor for entering a developer's name, role, introduction, and featured project.
- Theme customization with Midnight, Paper, and Violet visual styles.
- Live portfolio preview that updates when the user edits profile information.
- Responsive interface layout for different screen sizes.
- Consistent typography, spacing, and visual hierarchy.

## Files
- `PortfolioDesign.jsx` — React component containing the profile editor, theme selection, and live portfolio preview.
- `PortfolioDesign.css` — Styling for the layout, themes, typography, interactive states, and responsive behaviour.

## Next Steps
Integrate the design prototype into the main application, refine the interface based on team feedback, and test usability and responsiveness.
