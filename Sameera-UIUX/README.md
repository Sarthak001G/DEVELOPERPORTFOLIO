# Sameera Khan — UI/UX Design Contribution

**Project:** Developer Portfolio & Case-Study Builder  
**Contribution area:** UI/UX Design & Visual Design

## What this prototype demonstrates
- A profile-editing panel for name, role, introduction and featured project.
- Three selectable visual themes: Midnight, Paper and Violet.
- A live portfolio preview that updates as profile fields are edited.
- A responsive layout for desktop and smaller screens.
- A clear sequence: Profile → Style → Preview.

## Add to the team's React + Vite project
1. Copy `PortfolioDesign.jsx` and `PortfolioDesign.css` into the app's `src` folder.
2. Import and render the component from the appropriate page, for example:
   `import PortfolioDesign from "./PortfolioDesign";`
3. Run the project and review the design at desktop and mobile widths.

This is a UI/UX prototype/concept, not a claim that the complete portfolio-generation system is finished. Confirm the integration path with the team before merging.
